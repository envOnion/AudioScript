Первая русская версия AudioScript на основе проекта niyongsheng/AudioScript.

- Полностью русский интерфейс, трей, настройки, сообщения разрешений и экспорт.
- Офлайн-направления английский → русский и русский → английский.
- Встроенные модели потокового распознавания обоих языков и две модели OPUS-MT / CTranslate2 int8.
- Исправлены запуск и сборка через Bun, зависание упаковки DMG.
- Отдельный канал обновлений форка; телеметрия исходного проекта отключена.

Сборки: macOS 14.2+ (Apple Silicon и Intel), Windows x64 (EXE/MSI), Ubuntu 24.04+ x64 (DEB/AppImage). Языковые модели включены; после установки перевод работает без сети. Перевод появляется после завершения фразы.

Установщики не имеют Apple Developer / Authenticode-подписи. Пакеты автоматического обновления подписаны собственным ключом форка. SHA-256 файлов — в SHA256SUMS.txt.

Проверка сборок на GitHub Actions не заменяет проверку захвата звука и поведения окон на физических Windows/Linux-компьютерах. В GNOME Wayland размещение поверх окон ограничено системой.

Оригинал: https://github.com/niyongsheng/AudioScript (MIT). Модели: sherpa-onnx / Vosk и Helsinki-NLP / OPUS-MT; лицензии и атрибуция доступны в разделе «Модели» приложения.
